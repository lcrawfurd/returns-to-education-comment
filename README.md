## Data Availability Statement

The analysis in this paper uses Clark and Nielsen's (2026) replication dataset, which they make publicly available alongside the published article in *Kyklos*. The file `Returns_to_education.dta` is an unmodified copy of their dataset. No new data were collected. The dataset can be downloaded directly from the *Kyklos* journal supplementary materials page.

**Rights:** The data are redistributed here for verification purposes consistent with academic fair use. If the journal requires a rights statement, please obtain explicit confirmation from the authors or the publisher.

## Instructions to Replicator

1. **Clone / download** this folder to your machine.
2. **Check the Stata path** in `run.sh` (line `STATA=…`). Edit if your Stata binary is elsewhere.
3. **Install Python packages**: `pip install -r requirements.txt`
4. **Run the master script** from the project root:
   ```bash
   chmod +x run.sh
   ./run.sh
   ```
   The script runs four numbered steps (Stata → R → Python figures → Python tables). An optional final step syncs outputs to an Overleaf folder via a local path; this step is specific to the author's machine and can be ignored.

5. **Verify outputs**: all figures in `output/figures/`, all tables in `output/tables/`.

**To perform a clean-run test:** delete `data/_r_copas_puniform_input.csv` and all files under `output/`, then re-run `./run.sh` from scratch.

### Note on log files

Stata's `-b` (batch) flag writes a log named `blog-other-methods-stata.log` to the current directory (the project root) in addition to the structured log at `output/stata_pub_bias_summary.log`. Both contain the same content. A file named `0` (Stata's stdout in batch mode) is also created at the root; these can be safely deleted.
